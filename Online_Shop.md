Полнофункциональное desktop-приложение для управления онлайн-магазином с поддержкой различных ролей пользователей и расширенной функциональностью, разработанное на основе [диаграммы Miro](https://miro.com/app/board/uXjVIqj6p4o=/).

## 🌟 Архитектура и ключевые компоненты

### 🏗️ Структура системы
Проект реализован с использованием многослойной архитектуры, где каждый компонент отвечает за определенную функциональность:

- **UI Layer** - Windows Forms интерфейсы для различных ролей пользователей
- **Business Logic** - Хелперы и сервисы, обрабатывающие бизнес-логику
- **Data Access** - Работа с SQLite базой данных через DatabaseHelper
- **Network Communication** - TCP-сокеты для чата поддержки

### 📡 Сетевой чат службы поддержки
Этот модуль реализует функционал реального времени для общения между клиентами онлайн-магазина и службой поддержки через TCP-сокеты.

#### Архитектура и компоненты чата
Система состоит из двух основных частей:

**Сервер чата (ChatServer):**
- Консольное приложение, выступающее центральным хабом для всех сообщений
- Прослушивает входящие подключения на localhost:8888
- Многопоточная архитектура - для каждого клиента создается отдельный поток
- Обеспечивает одновременную работу с множеством пользователей

**Клиентская часть (SupportHelper):**
- Интегрирована в главное Windows Forms-приложение
- Управляет подключением к серверу, отправкой и получением сообщений
- Синхронизирует сетевую коммуникацию с локальной SQLite базой данных

#### 🚀 Ключевые функции чата
- **Обмен сообщениями в реальном времени** - минимальная задержка коммуникации
- **История сообщений** - все сообщения сохраняются в локальной БД
- **Уведомления** - всплывающие оповещения о новых сообщениях
- **Автоматическое переподключение** - механизм восстановления соединения
- **Многопользовательский режим** - одновременная работа с множеством клиентов

#### 📋 Протокол и формат данных
- **Протокол:** TCP (гарантированная доставка пакетов)
- **Порт:** 8888
- **Кодировка:** UTF-8 (поддержка кириллицы)
- **Формат сообщений:** Простая текстовая строка

## 🚀 Запуск и использование

### Предварительные требования
- **ОС:** Windows 7/8/10/11
- **.NET Framework:** 4.7.2 или выше
- **IDE:** Visual Studio 2019/2022 (рекомендуется)

### Инструкция по установке

1. **Клонирование репозитория**
```bash
git clone https://github.com/yourusername/online-shop-system.git
cd online-shop-system
```

2. **Запуск сервера чата**
```bash
# Запустите Server_Online_Shop.exe перед запуском основного приложения
Server_Online_Shop.exe
```

3. **Настройка клиента**
- Откройте `Online_Shop_Pet_Project.sln` в Visual Studio
- Восстановите NuGet пакеты
- Запустите приложение (F5)

4. **Регистрация пользователя**
- Выберите роль (покупатель или сотрудник)
- Заполните необходимые данные
- Для сотрудников потребуется загрузка документов

## 🔧 Технические детали реализации

### Классы и методы (Основные)

#### Серверная часть (Server_Online_Shop.exe)
**ChatServer класс:**
- `Start()` - запуск сервера и прослушивание порта
- `HandleClient(object obj)` - обработка подключений клиентов
- `Stop()` - корректная остановка сервера

#### Клиентская часть (Online_Shop_Pet_Project.exe)
**SupportHelper класс:**
- `InitializeNetwork()` - установка TCP-подключения
- `ReceiveMessages()` - асинхронное получение сообщений
- `SendNetworkMessage(string message)` - отправка сообщений
- `ShowChatWithSupport()` - отображение интерфейса чата

## 🎯 Особенности реализации

### 💾 Интеграция с базой данных
Сетевой модуль тесно интегрирован с локальной SQLite базой данных:
- Автоматическое сохранение истории сообщений
- Восстановление переписки при перезапуске
- Синхронизация между сетевым и локальным хранилищем

### 🔄 Механизм переподключения
- Автоматическое определение разрыва соединения
- Попытки переподключения с экспоненциальной задержкой
- Сохранение непрочитанных сообщений во время простоя

### 👥 Многопоточность
- Каждый клиент обрабатывается в отдельном потоке
- Неблокирующий UI во время сетевых операций
- Thread-safe доступ к общим ресурсам

## ⚠️ Важные особенности и ограничения

### Текущие ограничения
- **Локальный хост:** Сервер и клиенты должны находиться на одной машине (127.0.0.1)
- **Простой протокол:** Сервер отправляет автоматические ответы-подтверждения
- **Масштабируемость:** Требуется доработка для работы в распределенной сети
